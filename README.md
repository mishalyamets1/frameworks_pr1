# Система учета заявок на обслуживание помещений

## Назначение
Приложение предназначено для регистрации, отслеживания и управления заявками на обслуживание и ремонт помещений. Система помогает централизованно фиксировать проблемы, назначать исполнителей и контролировать сроки выполнения работ.

## Целевая аудитория
- **Сотрудники организации** — создают заявки на устранение неисправностей в своих помещениях.
- **Администраторы и диспетчеры** — принимают заявки, распределяют задачи и контролируют их выполнение.
- **Технический персонал** — получает назначенные заявки и отмечает выполнение работ.
- **Руководство** — просматривает статистику и отчёты по обслуживанию помещений.

## Основные сущности
 - Заявка — обращение на выполнение работ по обслуживанию помещения с описанием проблемы, приоритетом и статусом.
 - Помещение — объект обслуживания с указанием адреса, этажа и типа (офис, переговорная, склад и т.д.).
 - Пользователь — участник системы с ролью (заявитель, диспетчер, исполнитель, администратор).
 - Категория работ — тип обслуживания (электрика, сантехника, уборка, климат и др.).
 - Исполнитель — сотрудник или бригада, назначенная на выполнение заявки.
 - Комментарий — запись о ходе выполнения работ или уточнение деталей заявки.

## Что умеет (ПР2)
- просмотр и добавление помещений;
- поиск помещений;
- создание и просмотр заявок;
- назначение исполнителя и смена статуса;
- добавление комментариев;
- сохранение данных в JSON.

Функции из ПР1 (`create_request_details`, `executor_and_update_status`, `add_comment`) сохранены в модуле `tickets.py`.

## Предметная область
Система охватывает процесс обслуживания зданий и помещений: от момента обнаружения проблемы (протечка, 
неисправность оборудования, необходимость уборки и т.д.) до её устранения. Включает учёт помещений, 
категорий работ, приоритетов заявок и истории выполненных обслуживаний.

## Структура
```

```
